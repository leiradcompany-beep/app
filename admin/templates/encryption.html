Why Backend-Only Encryption?

Secure Key Storage

Encryption keys (APP_KEY) are stored securely on the server and never exposed to the frontend.

Tamper Protection

Laravel's encryption includes MAC (Message Authentication Code) to detect any tampering.

Rate Limiting

Endpoints are rate-limited to prevent brute-force attacks and abuse (30/min encrypt, 20/min decrypt).

Audit Logging

All encryption/decryption attempts are logged for security monitoring and compliance.
